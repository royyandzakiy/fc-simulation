# stable-baselines3 -> PyTorch (several GB) that this bridge never imports:
# it only uses CtrlAviary. Install this file with --no-deps; requirements.txt
# already pins everything CtrlAviary needs at runtime.
#
# --ignore-requires-python is needed too. Upstream declares >=3.12, but the
# package is pure Python and runs fine on 3.11, which is what pybullet's
# source build is verified against here. Drop the flag if you move to 3.12.
#
#   pip install --no-deps --ignore-requires-python -r requirements-gpd.txt
#
